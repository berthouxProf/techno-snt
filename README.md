# Techno & SNT – site des élèves

Site statique (HTML uniquement) publié avec GitHub Pages.

## Organisation

```
index.html              page d'accueil (liste des ressources)
5eme/  4eme/  3eme/     un sous-dossier par sujet
seconde-snt/le-web/     La Quête du Web
projets/jeux-video/     Forge 2D
outils-classe/          limitateur de volume, élections de classe
```

## Ajouter une page

1. Dépose le fichier `.html` dans `niveau/sujet/` (noms en minuscules, sans accents ni espaces).
2. Ouvre `index.html`, copie une ligne du tableau `RESSOURCES` et adapte-la.
3. Enregistre les deux fichiers sur GitHub (commit) : le site se met à jour en 1 à 2 minutes.

Voir `TUTO-MISE-EN-LIGNE.md` pour la procédure complète.
